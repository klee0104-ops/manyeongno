# v0.9 — 연속 이동과 도착 시점에 맞는 타격

## 연출 방향

사용자가 요청한 별이되어라·세븐나이츠 계열의 파티 전투 감각에 맞춰, 근접 공격자가 계속 보이는 상태로 접근하고 무기 접촉과 피격 반응이 한 순간에 읽히도록 구성했다. 현재 요괴 그림과 전투 규칙을 사용한다.

공식 참고 자료:

- [넷마블: 세븐나이츠 리버스 전투·스킬 연출 소개](https://ch.netmarble.com/Games/Detail?bbs_code=1004&post_seq=5229)
- [플린트: 별이되어라2의 2D 파츠 움직임과 즉각적인 액션 피드백](https://www.flintgames.co.kr/board/news/563?page=1) — 원작 별이되어라와 다른 후속작이므로 파츠 움직임의 보조 자료로만 참고했다. 이번 변경은 기존 파티 전투를 유지한다.

## 표시와 이동

- 전투 전용 `battle-sprite`를 사용한다. 여러 프레임이 있는 요괴는 항상 하나의 완전한 그림을 표시한다. 공격 시 머리·상체·발 레이어를 숨기고 다시 보이는 방식은 사용하지 않는다.
- 전투 캐릭터와 그 부모에 중첩되던 `drop-shadow`, 명도/채도 필터를 제거했다. 그림자는 발밑의 별도 타원으로 표시하며 살아 있는 캐릭터의 불투명도를 낮추지 않는다.
- 새 전장·보스의 이미지 시트를 디코딩한 후 첫 동작을 시작한다. 기다리는 중에도 후퇴 시 즉시 취소된다.
- 이동 시 실제 시트의 0→1→0→2 걷기 자세를 반복하고 상체의 기울기·발 구르기·착지 먼지를 함께 사용한다. UV는 계단식으로 바꾸므로 시트 사이의 빈 공간을 보간하지 않는다.
- 단일 포즈만 있는 추가 요괴는 상체와 좌우 하체를 분리해 발을 교대로 움직인다. 모든 요괴에 새 수작업 프레임 시트를 제작한 것은 아니다.
- 접촉 위치는 대상의 발 위치를 기준으로 계산한다. 귀환에도 걷기 동작을 유지한다. 날개·도약형은 높은 곡선, 일반 근접은 낮은 이동 궤적을 사용한다.

## 투사체와 접촉

- 손 앞에서 시작해 대상 몸통에 도착하는 곡선 궤적을 사용한다. 매 구간의 진행 방향으로 그림과 뒤쪽 잔상을 회전시킨다. 아군·적의 발사 방향을 모두 계산한다.
- 원거리 공격자는 자기 자리에 남는다. 짧은 모바일 거리에서도 투사체가 보이도록 비행 시간은 320~620ms(1배속)를 유지한다.
- 여우불의 곡선 연사, 죽엽 비수의 부채꼴 비행, 검의 낙하, 해일의 광선 확장을 구분한다. 궁극기 투사체 수는 목표 수에 따라 나눠 과밀한 화면을 줄였다.
- 피해와 체력 변화는 각 투사체가 도착할 때 발생한다. 근접 연권은 세 번, 검격은 두 번의 접촉에 맞춰 나눠 표시한다. 총 피해·흡수량과 전투 계산은 기존 수치를 보존한다.
- 각 접촉에서 무기 궤적, 속성 충격, 피해 숫자, 효과음, 맞은 쪽의 반동을 함께 재생한다. 48~85ms의 짧은 타격 정지를 사용하고 강한 타격만 전장을 2~3px 흔든다. 화면 전체를 검게 덮는 연출은 없다.
- OS의 동작 줄이기 설정에서는 큰 이동·반동·타격 정지를 생략한다.

## 시간축과 취소

`BattleTimeline`의 한 시간축으로 이동, 걷기, 투사체, 피격, 피해 표시를 구동한다. 일시정지·설정 모달·탭 숨김은 같은 위치에서 모든 동작과 예약된 타격을 멈춘다. 후퇴는 대기 중인 동작과 효과를 취소한다. 기존 기술명 음성과 로컬 저장 형식은 유지했다.

## 확인 기록

- 전체 167개 테스트 / 20개 파일 통과. 타입 검사·린트·에셋 검사 통과.
- 새 테스트: 걷기 프레임의 불연속 UV, 양방향 곡선 끝점·방향, 모바일 비행 시간, 연타 피해 보존, 71종 기본/각성 전투 그림 구조, 일시정지/숨김/타격 정지/중도 취소.
- PC와 390px 모바일에서 대표 12개 동작씩 브라우저 검사: 숨겨진 프레임 0. 프레임 시트가 있는 근접 캐릭터의 이동 중 3개의 걷기 UV 확인.
- PC의 근접 이동 폭 약 269~277px, 모바일 약 46~54px. 원거리의 9~24px 폭 변화는 자세 기울기이며 위치 이동은 하지 않는다.
- 달리기 도중, 여우불 비행 도중, 연권 접촉 순간을 정지해 직접 화면 확인. 색상 유지, 투사체 뒤쪽 잔상, 실제 적 앞에서의 무기 접촉 확인.
- 실제 로컬 게임의 1-8·1-9 전투 승리 확인. 1-9 이동 중 일시정지 → 설정 열기/닫기에서 산군의 동일 이동 행렬 `matrix(1, 0, 0, 1, 14.0294, 42.0597)` 유지 후 재개 확인.
- 모바일 가로 넘침 없음: 문서 폭/클라이언트 폭 모두 384px(390px 뷰포트의 스크롤바 제외).
- 개발용 검증 화면은 `tmp/`에 있으며 배포에 포함하지 않는다. 사용자 플레이 주소의 저장 데이터는 테스트에 사용하지 않았다.
