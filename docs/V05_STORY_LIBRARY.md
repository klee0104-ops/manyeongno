# 만령로 v0.5.0 — 달빛 서고의 이야기

## 입장과 이야기

닉네임으로 시작하면 필요한 장면 그림과 첫 내레이션을 로드합니다. 진행률은 실제 파일 응답에 맞춰 갱신합니다. 준비가 끝나면 **스토리 감상하기 / 바로 탐험하기**를 선택합니다. 감상과 건너뛰기에는 행동력을 사용하지 않습니다.

20개 챕터 각각 서막 3장면, 종막 3장면으로 구성했습니다. 기존 기획에서 가져온 서사와 추가 장면 설명은 `src/data/storyScenes.json`에 있습니다. 기존의 구미호 보행 스프라이트와 관련 이야기 CSS는 제거했습니다. 지역 배경과 인물의 등장, 촛불·지도 경로·저승문·명부의 먹빛·떠오르는 검·물결·부적·별빛·경계옥 등을 장면에 맞춰 조합합니다.

장면은 일러스트에 카메라 이동과 여러 겹의 2D 효과를 적용한 방식입니다. 모든 동작을 프레임별로 그린 장편 애니메이션 영상은 아닙니다. 동일 지역의 배경은 공유하며, 인물은 등장·실루엣 연출을 사용합니다.

한국어 Windows TTS `Microsoft Heami Desktop`으로 내레이션 120개, 약 598초를 미리 제작했습니다. 22.05kHz / 16비트 / 모노 WAV 약 26.4MB를 빌드에 포함합니다. 실제 플레이에는 Windows TTS 설치나 온라인 음성 API가 필요하지 않습니다.

- 음성이 끝나면 다음 장면으로 넘어갑니다.
- 이전/다음/특정 장면 선택, 일시정지/계속, 음성 켜기/끄기, 감상 종료를 지원합니다.
- 음성 재생이 차단되면 수동 음성 재생 버튼을 표시하고 자막으로 진행합니다.
- 창이 숨겨지면 일시정지합니다. 종료할 때 음성과 타이머를 정리합니다.
- 배경음악은 이야기 감상 중 낮아지고, 종료하면 설정 음량으로 돌아옵니다.
- 음성 선호도는 `manyeongno:narration`에 따로 보관합니다. 배경음악 설정과 독립적입니다.
- 탐험의 이야기 감상에서 해금된 챕터의 서막을 다시 봅니다. 종막은 해당 챕터 평온 보스 정화 후 열립니다.

## 만령서고

도감 메뉴는 달빛 서고로 들어갑니다. **요괴도감**은 기본 수집 65종, **각성비록**은 1~5단계 325개 기록을 다룹니다. 여섯 지역의 장서는 해당 지역으로 미리 걸러진 요괴도감입니다.

책 표지를 누르면 제본 표지가 펼쳐지고, 목차에서 요괴를 누르면 책장이 넘어갑니다. 펼친 책 왼쪽에는 전신 그림과 요괴의 한마디, 오른쪽에는 이야기·기술·능력치·만나는 방법이 있습니다. 각성비록에서는 해금 여부와 단계별 누적 효과, 재료, 전투 모습, 5각성 외형을 확인합니다.

이름 검색, 오행·지역·등급·보유 필터, 정렬, 이전/다음 책장·요괴를 지원합니다. 그림을 누르면 전체 일러스트가 확대됩니다. 나의 요괴나 소환 상점으로 이동할 수도 있습니다. 모바일은 두 페이지를 세로로 이어 읽습니다. 동작 줄이기 설정에서는 표지 회전 등 움직임을 생략합니다.

## 저장과 실행

기존 저장 키 `manyeongno:adventure:v2`와 모든 재화·요괴·장비·천장 기록을 유지합니다. 서고의 열람 상태는 저장된 성장을 변경하지 않습니다. `게임 실행.cmd` 또는 `npm start`로 플레이합니다. 서버의 WAV MIME 처리를 추가했습니다.

음성 재생성은 선택 사항입니다. 한국어 Windows 음성이 설치된 환경에서 `scripts/generate-story-audio.ps1`을 실행합니다. 서사를 변경할 때는 `scripts/create-story-scenes.py`의 장면 방향과 캠페인 원문을 수정한 뒤 JSON과 음성을 순서대로 재생성합니다. `npm run test:assets`가 자막과 음성 목록의 일치, WAV 형식·길이·비어 있지 않은 파형, 배경 파일을 검사합니다.

## 검증

- 타입 검사, ESLint, 14개 테스트 파일의 129개 테스트 통과.
- 120개 음성 파일과 자막 일치, 파형·재생 길이 검사 통과.
- 별도 개발 프로필에서 입장 로딩, 내레이션 실제 재생·일시정지·장면 이동·음소거·자동 종료 확인.
- 서고 표지, 기본/각성 책 전환, 단계 선택, 그림 확대와 책 복귀, 모바일 검색 및 지부신구 전신 표시 확인.
