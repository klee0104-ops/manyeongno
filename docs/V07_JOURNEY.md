# v0.7 이어지는 여정

## 플레이 흐름

첫 여정은 로딩 → 프롤로그 → 1장 서막 → 초행 길잡이로 이어집니다. 이야기를 건너뛸 수 있으며 이야기 감상에서 다시 재생합니다. 초행 길잡이는 실제 요괴 성장, 첫 스테이지 승리, 임무 보상 수령을 확인합니다. 설정에서 다시 열 수 있습니다.

20개 챕터마다 평온 난이도 5·10·15단계를 처음 정화하면 다음 전투에 앞서 짧은 이야기를 재생합니다. 20단계는 기존 종막으로 이어집니다. 각 장면에는 한국어 음성, 자막, 배경과 소품 애니메이션이 있으며 재생/일시정지·장면 이동·건너뛰기를 지원합니다. 전투가 뒤에서 동시에 진행되지 않습니다.

## 조작과 전투

- 같은 화면을 갱신할 때 문서, 모달, 상세 내용의 스크롤과 선택한 버튼 포커스를 복원합니다. 탐험 진입 때 한 번 전장으로 이동하고 전투 종료 후 지도 위치로 돌아갑니다.
- 구미호의 기본 전신 삽화는 실제 알파 투명 PNG를 사용하며 밝은 털과 옷은 불투명하게 유지합니다.
- 스킬 종류에 따라 화염·여우불·파도·검격·발톱·바위·번개·독·잎·회복·방어 문양을 사용합니다. 광역 투사체는 각 대상까지 날아갑니다.
- 타격 시점에 체력과 보호막을 갱신하며 피격 반동, 치명타 충격, 보호막 흡수 수치와 쓰러짐을 표현합니다. 동작 줄이기 환경에서는 큰 이동 효과를 줄입니다.
- 닉네임, 보유 요괴 초상, 진행 조건을 채운 칭호를 프로필에서 변경합니다. 기존 v2 저장 형식에 선택 필드를 더해 예전 저장도 읽습니다.

## 검증

151개 자동 테스트, TypeScript와 ESLint 검사, 한국어 이야기 184개와 상점 5개 음성의 존재·대본·무음 여부 검사 및 프로덕션 빌드를 통과했습니다. 이야기 음성 합계는 약 19분입니다.

브라우저에서 새 여정, 프롤로그, 실제 성장과 첫 승리·임무 수령, 연속 레벨업 스크롤 복원, 투명 구미호, 프로필 수정·재접속과 전투 효과를 확인했습니다. 1-5 승리 → 중간 이야기 → 1-6 전투 연결과 390px 모바일 프로필·이야기 목록도 확인했으며 브라우저 경고·오류는 없었습니다. 진행된 저장은 별도 로컬 테스트 주소에서만 사용합니다.

이 빌드는 로컬 저장을 사용하는 플레이 테스트입니다. 기존 도트의 영역별 애니메이션과 SVG 효과를 결합했으며, 모든 캐릭터를 새 프레임 시트로 교체하거나 온라인 계정 서버를 추가한 버전은 아닙니다.
