# v0.4.1 — 도감 분리와 인연상회

## 도감

- 기본 요괴 도감과 각성 도감을 별도 화면으로 분리했습니다. 기본 도감 65종과 각성 325단계의 수집 수를 따로 표시합니다.
- 기본 도감은 보유 요괴가 각성했어도 기본 외형으로 보여줍니다. 도감 번호와 오행·역할·지역·등급·보유 여부·획득 경로를 표시합니다.
- 지역/등급/오행/수집 상태를 함께 필터링하고, 이름 검색·정렬·18종 단위 페이지 이동을 지원합니다. 검색 중 입력 포커스를 유지합니다.
- 스토리 동료는 소환 요괴와 구분해 합류 챕터를 표시합니다.
- 각성 도감에서는 요괴별 1~5단계와 현재 해금 상태를 볼 수 있습니다. 미해금 모습도 미리 볼 수 있으며 실제 각성 상태는 변경하지 않습니다.
- 각 단계의 능력치 보너스, 레벨 상한, 스킬 계수, 필요 레벨과 재료를 실제 성장·스킬 설정에 연결했습니다.
- 대표 6종은 5각성에 전용 외형을 보여줍니다. 1~4각성은 기본 외형을 유지하고, 그 외 요괴의 5각성은 오라로 구분합니다. 새 일러스트를 추가한 업데이트는 아닙니다.
- 요괴 상세에서 각성 도감으로, 각성 도감에서 성장/소환/스토리 합류 경로로 이동합니다. 전신 확대 후에는 같은 도감으로 돌아갑니다.

## 소환 상점

- 소환 메뉴를 누르면 백귀정의 등불 배경을 사용하는 인연상회로 이동합니다.
- 달빛 인연 픽업: 구미호 전신, 소환 가능 요괴 61종, 확률 안내, 현재 천장과 픽업 보장을 표시합니다.
- 1회/10회 선택 → 비용·잔액 확인 → 소환 연출 → 결과 → 상점 복귀 흐름입니다. 확인창 취소는 재화를 소모하지 않습니다.
- 정수 교환: 보유 요괴를 선택해 정수 100을 전용 각성석 1개로 교환합니다. 4~5성은 각성석 1개를 돌파 혼편 5개로 바꿀 수 있습니다. 기존 경제 함수를 사용합니다.
- 소환 가격·확률·천장·저장 키와 파일 형식을 유지했습니다. 실제 결제 기능은 추가하지 않았습니다.
- 모바일에서도 상점 첫 화면 안에 소환 버튼을 배치하고, 동작 줄이기 환경에서는 장식 애니메이션을 정지합니다.

## 검증

- `npm run verify`: 타입 검사, ESLint, 13개 파일의 125개 테스트, 프로덕션 빌드 통과.
- 별도 개발 주소 5192에서 상점 진입, 10회 소환 취소, 1회 소환의 정확한 300 차감, 소환 결과와 천장 갱신을 확인했습니다.
- 지부신구를 선택해 정수 100 → 각성석 1, 각성석 1 → 혼편 5 교환과 각성 도감 연결을 확인했습니다.
- 기본 도감의 지역+등급+이름 복합 필터, 각성 단계별 수치와 전신 확대를 확인했습니다.
- 390×844에서 도감·전신 확대·상점의 가로 넘침이 없고, 브라우저 오류 기록도 없었습니다. 검증용 화면 크기를 원래대로 복원합니다.
- 실제 사용자 저장은 검증에 사용하지 않았습니다.
