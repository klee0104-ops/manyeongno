# 만령로 — 살아나는 인연 v0.10.0

기획 PDF와 제공된 일러스트를 참고한 로컬 2D 요괴 수집 RPG입니다. 기존 여정을 이어서 플레이할 수 있습니다.

### v0.10.0 · 경계의 시련

- 책의 앞면·뒷면을 분리해 앞으로/뒤로 넘길 때 삽화와 글자가 반전되던 문제 수정.
- 더 빠른 2배속·4배속, 배속 중 기술 음성과 공격을 동시에 진행.
- 속성별 발동 문양, 궁극기 입자·충격파·큰 명중 효과와 타격 정지.
- 승리 후 3초 뒤 다음 단계로 이어지는 연속 탐험. 새 이야기·장 완료·패배·행동력 부족 시 중단.
- **시련** 메뉴: 재화별 일일 던전 4종, 3단계 난이도, 던전별 하루 3회.
- 끝없는 미궁: 층별 성장·오행 결계·5층마다 보스와 추가 보상, 최고 기록 저장.

## Git으로 받아 실행하기

Node.js 22 이상과 Git을 준비한 뒤 실행합니다.

```sh
git clone https://github.com/klee0104-ops/manyeongno.git
cd manyeongno
npm ci
npm run build
npm start
```

서버가 표시하는 `http://127.0.0.1:5173/`에 접속하세요. Git 저장소에는 소스와 게임 리소스가 들어 있으며, 최초 실행 전 빌드가 필요합니다.

## 실행

**`게임 실행.cmd`**를 더블클릭한 뒤 **http://127.0.0.1:5173/** 로 접속합니다. Node.js가 필요하며 서버 실행 중에 플레이할 수 있습니다. 현재 주소가 이미 켜져 있다면 새로고침합니다.

이 실행 방법은 `dist`가 포함된 배포 ZIP 또는 위의 빌드를 완료한 폴더에 해당합니다.

`localhost:5173`에는 다른 프로젝트가 열릴 수 있으므로 `127.0.0.1` 주소를 사용하세요.

## 도감과 소환 상점

- 도감에서 **요괴 도감 / 각성 도감**을 따로 선택합니다. 기본 수집 65종과 각성 325단계 기록을 분리합니다.
- 도감 번호, 지역, 등급, 오행, 보유 여부, 이름 검색, 정렬과 페이지 이동을 제공합니다. 스토리 동료는 합류 챕터를 표시합니다.
- 각성 도감은 1~5단계의 해금 상태, 효과, 레벨 상한, 재료, 전신 및 전투 모습을 보여줍니다. 미리보기는 실제 성장을 바꾸지 않습니다.
- 소환 메뉴는 **백귀정의 인연상회**로 이동합니다. 달빛 인연 픽업 소환, 정수 교환, 소환 가능 요괴와 확률을 확인할 수 있습니다.
- 1회/10회 소환은 사용 경계석과 남는 재화를 확인한 뒤 연출로 이어집니다. 기존 가격·확률·천장·저장 형식을 유지합니다.
- 정수 교환에서 보유 요괴를 골라 전용 각성석과 4~5성 돌파 혼편을 교환할 수 있습니다.

## 플레이 안내

1. 닉네임을 입력하고 로딩 완료 후 스토리 감상 또는 바로 탐험을 선택합니다. 이야기는 탐험의 **이야기 감상**에서 다시 볼 수 있습니다.
2. 탐험은 자동 진행합니다. 궁극기 AUTO/수동, 배속, 일시정지를 선택할 수 있습니다. 스페이스 키도 일시정지입니다.
3. 챕터의 평온 보스를 정화하면 다음 장으로 이동할 수 있습니다. 다음 난이도는 이전 난이도의 보스 완료가 필요합니다.
4. 신물 공방에서 요괴를 선택하고 장착 슬롯을 눌러 같은 부위의 장비를 비교하세요. 선택 장비를 눌러 강화·제련할 수 있습니다.
5. 각성석은 높은 등급의 중복 소환이나 요괴 정수 교환으로 구합니다. 혼돈 파편은 정예·보스 보상과 출석 등으로 얻습니다.
6. 도감 → 만령서고 → 각성비록에서 요괴를 선택하고 1~5단계의 모습과 효과를 읽을 수 있습니다. 그림을 누르면 전신 크게 보기가 열립니다.
7. 출석과 도감 보상을 확인하세요. 3성 스테이지는 1회/5회 소탕할 수 있습니다.
8. 설정에서 저장 JSON을 내보내거나 불러올 수 있습니다. 로컬 저장은 브라우저와 주소별로 분리됩니다.

## 개발과 검증

```sh
npm install
npm run dev
npm run verify
npm start
```

`npm start`는 `dist`의 완성 빌드를 제공합니다. 개발용 임시 파일과 검증 프로필은 배포 빌드에 포함되지 않습니다.

GitHub Pages용은 `npm run build:pages`로 별도 `dist-pages` 폴더에 생성합니다. [공유·배포 관리 안내](docs/SHARING.md)를 참고하세요.

## 구현 범위

[상세 구현 기록](docs/V04_IMPLEMENTATION.md), [아트 제작 기록과 프롬프트](docs/ART_V04.md)를 참고하세요.

이 버전은 로컬 플레이 빌드입니다. 온라인 계정·PVP·길드·실제 결제는 연결하지 않았습니다. 새 요괴와 보스는 개별 그림에 이동·시전·반동 연출을 적용하며, 대표 6종 외의 전용 각성 일러스트와 전체 요괴의 세분화된 프레임 애니메이션은 후속 범위입니다. 장비 100개 정의는 부위별 기존 아이콘을 재사용합니다. 스토리는 일러스트·다층 효과·TTS로 구성한 2D 장면 연출이며, 모든 동작을 프레임별로 그린 장편 애니메이션 영상은 아닙니다.

PDF에 없는 세부 성장 곡선·경제·스킬 수치는 로컬 빌드용으로 조정했습니다. 원본 PDF, 기존 v0.2/v0.3 아카이브와 참조 이미지는 보관했습니다.
