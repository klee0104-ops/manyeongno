# v0.8 전투 동작과 기술 외침

## 사라짐 수정

이전 공격 모션은 대기용 머리·상체·하체 레이어를 숨긴 뒤 단일 그림을 표시했습니다. 더 높은 우선순위의 CSS가 단일 그림의 배경을 숨겨 공격자가 투명해지는 문제가 있었습니다. 전투에서는 그림 레이어를 계속 유지하고, 같은 레이어의 포즈와 위치만 바꿉니다. 화면 갱신은 동작 종료까지 미루며 전투 중 모달을 닫아도 전장을 새로 만들지 않습니다.

## 무기와 접촉

| 요괴 | 표현 |
|---|---|
| 적염귀왕 | 상대 앞까지 접근 → 권갑 준비 → 세 차례 연권 → 불꽃 충격 → 복귀 |
| 만검혼 | 낮은 접근 → 교차 검격. 궁극기는 제자리에서 비검 낙하 |
| 구미호 | 방울·부적 시전 → 곡선으로 날아가는 여우불. 궁극기는 아홉 불꽃 |
| 심연마갈 | 부채 펼치기 → 부채꼴 물결. 궁극기는 넓은 해일 |
| 지부신구 | 기본 공격은 방패 밀기. 기술은 방패를 세워 대지 충격과 아군 보호막 |
| 산군 | 도약 → 발톱 접촉 → 짧은 착지·복귀 |
| 죽림뱀 | 기본 독니 찌르기와 기술의 죽엽·독 투사체를 구분 |
| 삼신동자 | 지팡이 시전 → 동료 자리에서 새싹 치유가 피어남 |

`src/data/combatChoreography.ts`가 모든 요괴 65종과 보스 6종의 무기, 동작, 전달 방식, 효과 문양, 기술 3종을 정의합니다. 동작 계열은 공유하지만 각 요괴의 조합과 기술을 명시적으로 지정합니다. 기본 공격과 두 기술·궁극기의 범위·역할은 기존 전투 계산을 사용합니다.

피격자는 자기 위치에서 3~7px의 짧은 반동을 보입니다. 공격자의 발 위치가 목표 발 위치와 맞도록 계산하고, 서로 겹쳐 가리지 않도록 접촉 간격을 둡니다. 전체 화면을 덮는 궁극기 컷인은 작은 기술명 안내로 바꿨습니다. 동작 줄이기 설정에서는 큰 이동과 반동을 생략합니다.

## 한국어 기술 음성

213개 기술명 파일은 설치된 Windows 한국어 TTS로 제작했습니다. 성우 71명의 서로 다른 목소리를 제작한 것은 아닙니다. 각자 다른 기술명을 짧게 외치며, 현재 음성을 끝내고 타격하기 때문에 대사가 쌓이거나 겹치지 않습니다. 일시정지·후퇴·전체 음소거·탭 숨김 시 현재 음성을 멈춥니다.

- 대본: `public/audio/combat/lines.json`
- 음성: `public/audio/combat/*.wav`, 총 약 364초, 가장 긴 기술명 2.17초
- 생성: `node scripts/export-combat-audio.mjs` → `powershell -File scripts/generate-combat-audio.ps1`
- 검증: `node scripts/verify-combat-assets.mjs`

목은 나무·잎의 짧은 마찰음, 화는 불꽃의 파열음, 토는 낮은 충격음, 금은 높은 금속음, 수는 부드러운 물소리로 타격음의 주파수와 필터를 구분합니다. 새로운 이미지 생성 없이 기존 도트와 코드 기반 SVG 문양을 사용합니다.

## 검증 범위

실제 전투 모듈을 사용하는 별도 개발 화면에서 근접, 원거리, 방벽, 치유, 비검, 도약, 용식 등 대표 동작 12개를 프레임 단위로 검사했습니다. 각 동작의 준비·접근·타격·복귀 동안 사라진 프레임은 0개였습니다. 개발 화면과 테스트 저장은 배포에 포함하지 않습니다.

자동 테스트는 접촉 간격과 발 위치, 원거리의 제자리 시전, 71종 기술 구성과 전투 로그·대사의 일치, 이전 저장 호환성, 음성 중단·중복 방지를 검사합니다. 음성 파일 검사에서 모든 파일의 PCM 형식·길이·무음 여부도 확인합니다.

159개 테스트와 TypeScript·ESLint·프로덕션 빌드를 통과했습니다. PC와 390px 모바일에서 대표 동작 12개씩 사라짐 0프레임을 확인했습니다. 실제 게임에서는 전투 승리까지 진행하고, 공격 준비 중 일시정지·기술 음성 OFF·설정 열기/닫기·같은 동작에서 재개를 확인했습니다. 모바일 가로 넘침도 없었습니다.
