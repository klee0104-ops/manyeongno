# v0.6 — 살아나는 인연

## 만령서고

이전 판의 평평한 종이 회전을 곡면 종이로 바꿨습니다. 이전 페이지를 복사한 9개 세로 띠가 서로 다른 각도로 휘어지며 1.25초 동안 이동합니다. 앞면과 뒷면에 실제 목차·삽화·내용이 인쇄되고 움직이는 그림자를 더했습니다. 새로운 삽화가 이전 종이를 뚫고 보이지 않도록 책과 애니메이션의 합성을 분리합니다. 빠른 연속 입력은 한 번의 책 넘김이 끝난 뒤 받습니다.

내부는 지역 풍경을 옅게 깐 삽화 면과 인물 기록 면으로 구성합니다. 인장, 비단 책갈피, 테두리, 금색 가는 선, 큰 첫 글자, 능력치 표와 넓어진 전투 모형 받침을 추가했습니다. 전신 삽화 확대, 지역·등급·오행·보유 필터, 검색, 65종 기본 도감과 325단계 각성 기록은 유지합니다. 모바일은 두 면을 세로로 배치하고 그 전체를 한 장처럼 넘깁니다.

## 살아 있는 대기 자세

기존 도트 그림을 머리·상체·하체 영역으로 나눠 호흡과 기울기 변화를 적용합니다. 발 쪽 움직임은 작게 유지하며 머리와 상체는 별도로 움직입니다. 수호·검객·치유·물결·여우·권사·짐승·뱀·부유의 9가지 유형을 무기와 역할에 맞춰 배정하고, 요괴마다 다른 재생 주기와 시작 시점을 사용합니다. 속성 입자와 바닥 그림자를 함께 움직입니다.

지부신구는 방패를 든 묵직한 자세, 만검혼은 작은 검객 호흡, 심연마갈은 유연한 물결, 삼신동자는 새싹의 빛, 적염귀왕은 큰 무게중심 변화, 구미호는 여우불과 가벼운 기울기를 사용합니다. 기본 모습과 각성 모습 모두 같은 대기 시스템을 사용합니다.

전투 전체의 모형 애니메이션을 멈추던 규칙을 제거했습니다. 공격하는 요괴는 이동·시전 동작으로 전환하고 나머지는 계속 호흡합니다. 피격자는 반동 동안 잠깐 멈춘 뒤 돌아오며, 전투 일시정지 상태에서는 대기 동작도 멈춥니다. 기존 돌진, 투사체, 피격 효과, 충격음과 궁극기 컷인은 유지합니다.

이는 기존 아트에 영역별 움직임을 더한 구현입니다. 모든 요괴에 새로운 프레임 시트를 손으로 그려 넣은 방식은 아닙니다.

## 백귀정 인연상회

소환을 누르면 문과 로딩 막대가 나타나 실제 상점 배경·할머니·인사 음성을 준비합니다. 문이 열리면 독립된 상점 공간으로 들어갑니다. 할머니가 “어서 오너라, 먼 길 오느라 고생했지. 무엇이 필요하니?”라고 인사하고 다음 두 선택지를 보여줍니다.

- **요괴 소환**: 기존 픽업 배너, 1회·10회 소환, 확률, 소환 가능 목록, 천장 안내, 특수효과와 결과 화면.
- **일반 상점**: 실제 구매 가능한 상품 4종과 각성 재료 교환소. 할머니에게 돌아가는 버튼과 가게 나가기 버튼을 제공합니다.

| 상품 | 가격 | 받는 효과 |
|---|---:|---|
| 달빛 약차 | 경계석 25 | 행동력 최대 30 즉시 회복 |
| 길잡이 부적 | 금화 2,500 | 소탕권 5장 |
| 반짝이는 강화석 | 금화 3,000 | 강화석 10개 |
| 정령의 이슬 | 금화 5,000 | 요괴 정수 50개 |

약차는 한 잔씩 사용하며 행동력이 가득 차면 구매할 수 없습니다. 상한에 가까우면 실제 회복량을 확인창에 표시합니다. 다른 물품은 한 번에 1~5묶음을 살 수 있습니다. 구매 전 총가격·받는 수량·남는 재화를 확인합니다. 재화 부족, 비정상 수량, 재료 보관 상한에서는 차감하지 않습니다.

할머니는 대기·눈 깜빡임·말하는 표정을 사용합니다. 한국어 TTS 음성 5종이 포함되어 외부 서비스가 필요하지 않습니다. 기존 내레이션 끄기 설정을 따르며 ‘다시 듣기’를 직접 누르면 해당 대사를 한 번 재생합니다. 새 대사, 소환 연출, 퇴장, 탭 숨김 때 겹쳐 재생하지 않도록 정리합니다. 음성 중에는 배경음악을 줄입니다.

## 저장과 검증

기존 저장 키와 구조를 유지합니다. 기존 닉네임, 요괴, 장비, 스테이지, 재화와 소환 천장을 그대로 사용합니다. 실제 결제는 없습니다.

- 구매 수량·총액·아이템 지급·재화 부족·행동력 상한·보관 상한·저장 직렬화와 대사 일치를 자동 테스트합니다.
- 기존 전투·성장·각성·도감 테스트를 함께 실행합니다.
- 120개 스토리 음성과 신규 5개 상점 음성의 WAV 형식·길이·실제 신호를 검사합니다. 새 PNG 크기와 할머니 시트의 투명 채널도 확인합니다.
- 개발용 별도 주소의 테스트 프로필에서 책의 양면 전환, 방패 및 물결 모형, 전투 중 비행동자 대기 지속·피격 후 복귀·일시정지, 구매 지급과 재접속 보유량, 한국어 음성 재생, 390px 모바일 상점과 가로 넘침을 확인했습니다.

검증 명령: `npm run verify`. 개발용 임시 파일, 테스트 프로필과 이전 ZIP은 배포 ZIP에 넣지 않습니다.
