# 만령로(萬靈路) 설계 수치 요약 (에이전트용 발췌)

이 파일은 전체 기획 브리핑(Claude Project 문서 `방치형게임_기획브리핑.md`, 이 세션에서는 접근 불가할 수 있음)에서
**코드 구현에 직접 필요한 수치·공식만** 발췌한 것이다. 최신 원본과 이 파일이 다르면 원본이 우선한다.
스토리·연출·수익화 설계 등 비수치 정보는 이 파일에 포함하지 않았다 — 필요 시 사용자에게 원본 문서 접근을 요청할 것.

## 4장 — 지역/챕터 구성
20챕터 × 6지역. `src/data/chapters.ts`의 `CHAPTER_META`에 이미 반영됨:
적요림(1-3) → 운봉협(4-7) → 백귀정(8-10) → 나가라 사원(11-13) → 초원의 하늘(14-16) → 경계의 끝(17-20).

## 11-4. 스테이지 유형 (챕터당 1~20)
- 5, 15번: 정예전
- 10번: 미니보스전
- 20번: 챕터보스전(50% 이하 HP에서 페이즈2 전환)
- 나머지: 일반전

## 11-5 / 11-6. 몬스터 스탯 스케일링
```
EnemyStat = 100 × RegionMult × ChapterStepMult × StageTypeMult × DifficultyMult
ChapterStepMult = 1.4 ^ (지역 내 챕터 순번 - 1)
BaseCurve(stageNum) = 1 + 0.05 × (stageNum - 1)
StageTypeMult = BaseCurve × 유형계수(일반1.0 / 정예1.6 / 미니보스2.2 / 챕터보스P1 3.5 / P2 4.55)
```
RegionMult: 적요림1, 운봉협5, 백귀정15, 나가라사원40, 초원의하늘90, 경계의끝200.
DifficultyMult: 쉬움1.0, 보통1.8, 어려움3.2, 지옥5.5.

검증값(`tests/enemyStat.test.ts`에 회귀 테스트로 고정됨): 1-1=100, 3-20(어려움,P1)≈4,280.64,
10-10(보통)≈16,881.48, 20-20(지옥,P2)≈2,678,075.4.

⚠️ EnemyStat을 ATK/DEF/HP로 나누는 정확한 배분 비율은 원본 문서에 없음 — `src/systems/enemyStat.ts`의
`splitEnemyStat()`은 placeholder(atk 30% / def 20% / hp 500%)다.

## 12-2. 스태미나
기본 최대치 120(계정레벨당 +1). 최초클리어 소모 6(난이도 무관). 반복파밍: 쉬움6/보통8/어려움12/지옥20.

## 14-1 / 14-4. 등급 & 레벨 캡
등급: 1성 잡귀 / 2성 영물 / 3성 신수 / 4성 신장 / 5성 신격.
기본 레벨캡: 1성40 / 2성50 / 3성60 / 4성70 / 5성80. 각성 1회당 +10(최대 5각성).

## 14-2. 가챠 확률 & 천장
기본 확률: 5성1.5% / 4성6% / 3성18% / 2성35% / 1성39.5%.
소프트천장 65회차부터 5성 확률 점증, 80회차 하드천장(100% 확정).
5성 등장 시 픽업 50%, 논픽업이면 다음 5성 100% 픽업 보장. 10연은 4성 이상 최소 1개 보장.

⚠️ 65~79회차 사이의 정확한 확률 증가 곡선은 문서에 수치식으로 없음 — `src/systems/gacha.ts`의
`rampFiveStarChance()`는 선형 보간 placeholder다.

## 14-7. 전용돌파
혼편 5개당 1회, 최대 3회. 1돌파: 스탯+8%, 상성유리 추가피해+5%. 2돌파: 스킬계수 +10%p.
3돌파(만돌파): 파티 지원형 패시브 1개 해금.

## 15-1. 스킬 슬롯 & 궁극기 게이지
AI 자동 사용 우선순위: 궁극기 > 스킬2 > 스킬1 > 기본공격.
게이지(0~100): 기본공격 적중 +10, 피격 +5, 스킬1 사용 +8, 스킬2 사용 +5, 매 턴 +3.

## 15-2. 오행 상성 (목·화·토·금·수)
상극 순환(유리 1.5배): 목→토, 토→수, 수→화, 화→금, 금→목. 피상극(불리) 0.7배. 그 외 중립 1.0배.
`src/systems/elements.ts`에 매트릭스로 구현됨.

## 15-3. 데미지 공식
```
RawDamage       = 공격자ATK × 스킬계수(%)
DefMitigated    = RawDamage × [100 / (100 + 방어자DEF × 0.5)]
ElementAdjusted = DefMitigated × 오행배율(1.5 / 1.0 / 0.7)
CritAdjusted    = ElementAdjusted × (크리 발생 시 크리데미지%, 아니면 ×1.0)
FinalDamage     = CritAdjusted × (1 + Σ버프% − Σ디버프%) × 랜덤변동(0.95~1.05)
```
최소 데미지 보장: FinalDamage ≥ RawDamage × 5%. 기본 크리확률 5%, 기본 크리데미지 150%.
검증 예시(`tests/damage.test.ts`): ATK500·계수230%·DEF300·상성1.5배·크리150% → Raw1,150→DefMit460→Elem690→Crit1,035.

## 15-4. 등급별 스킬 계수(%)
| 등급 | 기본공격 | 스킬1 | 스킬2 | 궁극기 |
|---|---|---|---|---|
| 1성 | 100 | 160 | — | 280 |
| 2성 | 100 | 175 | — | 320 |
| 3성 | 100 | 190 | 230 | 380 |
| 4성 | 100 | 205 | 260 | 430 |
| 5성 | 100 | 220 | 290 | 500 |

각성 보정: 1각성 스킬1+15%p, 2각성 스킬2+15%p, 4각성 궁극기+20%p.
궁극기가 상성 유리 대상 적중 시 오행배율 위에 추가 ×1.2배(최종 1.8배).

## 15-6. 버프/디버프 캡
버프 합산 최대 +100%, 디버프 합산 최대 -70%.

## 16-1. 파티 편성
5슬롯(전열 2 + 후열 3). 전열 전멸 시 후열이 자동으로 앞으로 당겨짐.

## 17-2 / 17-3. 로스터 (v23 기준)
5성 10종(오경수호신 5종 + 신규 개별 요괴 5종: 삼신동자·만검혼·적염귀왕·심연마갈·지부신구).
오조신(五祖神)은 v18부터 가챠 로스터에서 완전 제외 — 시즌2 스토리 전용. `src/data/units.sample.json`에
실제 로스터 중 7종을 샘플로 옮겨둠(전체 60종 로스터는 미착수).
