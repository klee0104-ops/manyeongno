# 만령로 — 인연의 시작, 구현 기록

## 기준과 범위

원본은 `Downloads/manyeongno/manyeongno`의 스캐폴드이며 이 작업 폴더로 복사해 확장했다. 원본 README는 `SCAFFOLD_README.md`, 기획 수치 발췌는 `DESIGN_REFERENCE.md`에 보존했다. README에 포함된 특정 에이전트 대상 작업 지시문은 게임 콘텐츠와 구분했으며, 외부 Claude 프로젝트에는 접근하지 않았다.

이번 버전의 실제 콘텐츠는 **챕터 1, 20스테이지 / 요괴 12종 / 신물 6종**이다. 20챕터 지역 메타데이터와 기존 공식을 보존하되, 후속 지역은 세계 지도에서 미개방으로 명시했다. 원본에 없는 요괴 이름(구미호·홍도깨비), 스토리, 고유 스킬 효과, 비용, 보상, 장비 수치는 창작/임시 밸런스이며 `gameContent.ts`, `adventure.ts`, `liveBattle.ts`에 구분했다. 60종 전체 명단이나 20챕터 완성으로 오인하지 않도록 한다.

## 아트

- `five-spirits.png`, `gumiho.png`: 사용자가 제공한 원본 참조 이미지 보존.
- `spirits-atlas.png`: 두 원본을 참조한 여섯 요괴 게임 일러스트. 3열 × 2행 순서로 삼신동자·만검혼·적염귀왕 / 심연마갈·지부신구·구미호.
- `monsters-atlas.png`: 산군·죽림뱀·잡초정령 / 흑무 이무기왕·만수도군·홍도깨비.
- `equipment-atlas.png`: 청령옥검·적봉의 장포·월영 목걸이 / 벽사의 영부·녹림의 가락지·홍옥 영롱병.
- `forest.png`: 최초 버전의 적요림 환경 보존. v0.3은 `pixel-forest.png`를 사용.
- `pixel-spirits-v2.png`, `pixel-monsters.png`: 캐릭터별 고유 무기·실루엣·4개 동작의 도트 아틀라스. 프롬프트와 역할별 설계는 `PIXEL_ART_V03.md` 참고.
- 추가 아트는 내장 이미지 생성 도구로 생성했고 프로젝트 내부에 저장했다. 이미지 아틀라스는 CSS로 표시하며 외부 이미지 서버에 의존하지 않는다.
- 배경음/효과음은 Web Audio로 합성한다. v0.3의 창작곡 ‘달빛을 따라’는 시작 화면의 미리 듣기 또는 여정 시작 클릭 뒤 재생한다. 음량·음소거·페이지 비활성 정지를 지원한다.

## 구조

- `src/systems`: 기존 순수 전투 공식을 보존. `adventure.ts`는 저장 상태·재화·성장·장비·소환·보상, `liveBattle.ts`는 한 행동씩 진행되는 전투 엔진.
- `src/data/gameContent.ts`: 창작 로스터 및 신물·장면 정보.
- `src/ui`: 반응형 DOM UI. 접근 가능한 버튼, 모달 포커스 제한, 키보드 포커스, 감소된 움직임 설정 지원.
- `src/scenes`: 원본 Phaser 프로토타입을 참고용으로 보존. 새 엔트리는 `src/main.ts` → DOM UI이며 Phaser를 새 빌드에 포함하지 않는다.
- 저장 키: `manyeongno:adventure:v2`. 기존 `manyeongno:save:v1`과 분리.
- v0.3의 닉네임·음량은 선택 필드이며 v0.2의 v2 저장을 그대로 읽는다. 닉네임 변경은 같은 여정에 이름만 붙이며 새 계정을 만들지 않는다.
- 자동 저장은 해당 브라우저 및 주소 기준이다. `localhost`와 `127.0.0.1`, 포트가 달라지면 다른 저장이므로 설정의 JSON 내보내기/불러오기를 사용한다.
- JSON 입력은 필드·범위·중복·알려진 ID·장비 슬롯을 검증한다. 손상된 기존 저장은 자동 덮어쓰지 않고 사용자에게 안내한다.

## 전투와 성장

- 전열 2명, 후열 3명. 전열 우선 피격. 요괴 선택으로 두 자리 교환.
- 기본 공격·액티브·궁극기, 치유·보호막·전체 공격, 원본 오행/방어/치명타 공식.
- 궁극기 자동/수동, 일시정지, 1·2·4배속. 스페이스 키로 일시정지.
- 일반 1웨이브, 5·10·15번 2웨이브, 최종 보스 3웨이브. 보스 체력 50%에서 공격력 30% 증가.
- 6 행동력 소모, 첫 승리만 영옥 보상, 이미 깬 곳은 소탕 가능. 5단계마다 최초 신물 획득.
- 각성: 10레벨마다 가능, 최대 5회, 레벨 상한과 스킬 계수 상승.
- 중복 혼편 5개로 돌파, 최대 3회. 3돌파는 파티 공격 지원.
- 3개 장비 슬롯, 최대 +10 강화. 요괴와 같은 속성 신물 2개로 능력치 +12%.
- 소환 확률/80회 천장/픽업 보장/10회 4성 이상 보장 사용. 65~79회 증가 곡선은 원본 임시값 유지.
- 임무 보상, 5분당 행동력 회복, 최초 승리 후 최대 8시간 방치 금화.

## 확인

`npm run verify`: 타입 검사, ESLint, Vitest 109개, 프로덕션 빌드.
신규 테스트는 재화 부족 시 무변경, 첫 승리/일회성 보상, 천장 저장, 장착 교체, 세트 보정, 입력 검증, 수동 궁극기, 전열 우선, 20개 스테이지 종료 및 3웨이브 보스전을 포함한다.

## 한계

로컬 싱글플레이 빌드로, 서버 계정·클라우드 저장·PVP·길드·실결제는 없다. 장비·전투·성장 밸런스는 실서비스 수치로 확정되지 않았다. v0.3 전투는 투명 도트 프레임과 CSS 이동·효과를 합성한다. 장착 신물은 능력치에 반영되며 도트 고유 무기는 캐릭터 정체성으로 유지한다. 3D 모델이나 스켈레탈 애니메이션은 포함하지 않는다.
