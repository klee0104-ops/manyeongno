# v0.4 구현 범위와 기획 반영

기준: 사용자 제공 `manyeongno_기획총정리.pdf`(34쪽)와 사용자가 직접 요청한 변경. 문서의 내용은 게임 기획 자료로만 사용했습니다. 작업 대상은 현재 프로젝트이며 다운로드 폴더의 사국영웅전 원본은 수정하지 않았습니다.

## 플레이 흐름

- 6지역, 20챕터, 400스테이지. 각 챕터 평온 보스를 완료하면 다음 챕터가 열립니다.
- 난이도 평온/균열/폭주/명계의 진행과 1~3성 기록을 각각 저장합니다. 이전 난이도의 챕터 보스 완료가 다음 난이도의 조건입니다.
- 모든 전투 2웨이브. 일반 4~6기, 정예 5·15번, 중간 보스 10번, 챕터 보스 20번. 보스 생명력 50%에서 2단계, 공격력 30% 상승. 명계는 최초/전환 보호막을 더합니다.
- 최초 미완료 스테이지 입장 6, 반복 6/8/12/20 행동력. 5분당 1 회복. 계정 진행에 따라 최대 120~220.
- 해당 난이도 3성 기록만 소탕 가능, 1/5회 묶음. 소탕권은 1회당 1장으로 행동력을 대체합니다. 명계 주 3회는 소탕에도 적용됩니다.
- 전투 승리 1성, 전원 생존 +1성, 30라운드 이내 +1성. 별점 세부 조건은 로컬 빌드용 기준입니다.
- 20장 완료 후 재봉인/대통합 결말 선택. 이후 환생 시 요괴·장비·소환 기록을 유지하고 탐험 기록을 초기화, 전체 능력치 +10%와 경계석 2,700 지급.

## 전투와 스토리 표현

- 전투 계산과 화면 연출을 분리했습니다. 준비 → 실제 좌표 이동/투사체 → 타격 순간 체력·피해 표시 → 짧은 정지·반동 → 복귀 순서입니다.
- 수호 방패 강타, 검 돌진, 권갑 타격, 부채 파동, 부적 투사체, 치유/보호막 효과. 궁극기 일러스트 컷인과 보스 2단계 전환.
- 공격 충격음은 저음의 빠른 음높이 하강과 짧은 노이즈, 치유/보호는 별도 음색. 기존 창작 BGM 유지, 음소거/음량/배경 탭 일시정지 지원.
- 챕터별 도입/종결은 자동 진행하는 2D 장면입니다. 카메라 이동, 도트 등장, 그림자/부적/경계옥, 내레이션 자막으로 구성하며 정지·건너뛰기·다시 보기를 지원합니다. 별도 영상 파일이나 음성 더빙은 아닙니다.
- 3/6/9/12/15장 종결에는 삼신동자·만검혼·적염귀왕·심연마갈·지부신구가 빛 속에 잠깐 등장합니다.
- 로그인에는 캐릭터가 없습니다. 챕터에 맞는 지역 배경과 서로 다른 박자로 숨 쉬는 등불, 안개·반딧불로 연출합니다.
- 소환 결과와 재화는 연출 전에 저장됩니다. 부적 집결 → 문 개방 → 등급별 섬광 → 대표 결과 등장 후 전체 결과 표시. 건너뛰기로 중복 결제되지 않습니다.
- 움직임 줄이기 설정을 따릅니다. 전투를 떠나면 진행 중인 연출을 취소하고 지연 콜백의 보상 중복 지급을 막습니다.

## 수집과 성장

- 기획 60종 + 기존 구미호 1종 + 스토리 동료 4종 = 65종. 각 요괴의 아트 칸은 서로 다릅니다.
- 검선/여우무녀/사원무희/초원예언자는 각각 5/9/11/14장 평온 보스 첫 완료에 지급합니다.
- 기존 등급별 레벨 상한과 각성 5회 유지. 각성석 + 혼돈 파편 + 금화로 각성합니다. 각성석은 고등급 중복 또는 요괴 정수 교환으로 구합니다.
- 1~3성 중복: 혼편 1 + 요괴 정수. 4~5성 중복: 전용 각성석 1 + 요괴 정수. 중복 인장은 요괴별 최대 5개입니다.
- 기획서의 '전 등급 돌파'와 '5성 혼편 없음'을 함께 만족시키기 위해 4~5성 전용 각성석 1개를 혼편 5개로 교환하는 선택지를 추가했습니다. 각성/돌파 중 어디에 사용할지 플레이어가 선택합니다.
- 대표 6종의 5각성: 새 전신 일러스트와 전용 도트 시트. 다른 요괴는 진명 오라와 능력 강화. 모든 65종의 별도 각성 일러스트를 완성한 상태는 아닙니다.
- 수집·중복 인장·오행 5/10/20종 도감 공명, 10/30/50/70/100% 수집 보상. 리더 1명의 역할에 따른 파티 공격/방어/생명 +8%.
- 30일 출석, 7/14/21/30일 추가 선물, 매일 행동력 20, 기존 임무와 8시간 방치 금화.

## 장비

- 사국영웅전 v1.5 HTML의 장착 대상 선택, 슬롯 필터, 다른 영웅 장착품 분리, 자동 장착·해제 흐름을 참고했습니다.
- 병기/보구/영패/부적 4부위, 오행별 5등급 100개 정의 + 기존 장비 6개 보존.
- 캐릭터 중심 장착 슬롯, 교체 능력치 증감, 같은 속성 2부위 +12% / 4부위 +25%.
- +15 확정 강화, 강화석 소모. 미장착 +0 장비 3개로 다음 등급 제련. 부위·등급을 맞추고 선택 장비의 오행을 유지합니다.
- 범상 제작: 금화 600, 요괴 정수 15. 장비는 소환 풀에 들어가지 않습니다.
- 오행 장비는 기존 6종 아이콘을 부위에 맞게 재사용합니다. 100개 정의마다 별도의 장비 그림을 제작한 것은 아닙니다.

## 저장 이전과 수치

- 저장 키 `manyeongno:adventure:v2` 유지. `campaign` 필드를 선택적으로 추가하여 기존 파일을 읽습니다. 기존 요괴/레벨/각성/혼편/장비/소환 천장을 보존하고 옛 챕터1 기록은 평온 3성으로 이전합니다.
- 기존 벽사의 영부만 새 부적 슬롯으로 분류합니다. 기존 강화 수치를 유지합니다.
- 처음 확장할 때 강화석 40, 혼돈 파편 10, 소탕권 5를 지급합니다. 필드가 존재하면 다시 지급하지 않습니다.
- 시작 화면만 열어 둔 오래된 탭은 주기적으로 저장을 덮어쓰지 않습니다. 입장 직전에 최신 저장을 다시 읽습니다.
- PDF에 없는 성장 곡선·보상·제작비·개별 스킬·세부 패턴은 로컬 빌드용 조정입니다. 20레벨 이후 매 레벨 1.055배 성장을 더해 문서의 후반 지역 배수에 도달할 수 있게 했습니다. 전체 장기 경제 밸런스를 실사용 기간만큼 검증한 것은 아닙니다.

## 검증 및 남은 범위

- 타입 검사, ESLint, 경제/저장/전투 단위·통합 테스트. 400개 평온 전투를 상한까지 성장한 편성으로 종료·승리할 수 있는지 확인합니다. 모든 성장 구간/편성을 자동 승리로 맞춘 것은 아닙니다.
- 2026-09-18 최종 `npm run verify`: 타입 검사·ESLint·13개 테스트 파일의 125개 테스트·프로덕션 빌드 통과.
- 별도 개발 주소 5192에서 첫 전투와 보상, 최종 보스 혼원 2단계와 대통합 결말, 10회 소환, 각성 전신, 장비 추천·강화를 실제 UI로 검수했습니다. 390×844 모바일 로그인·장비·전신 확대도 확인했으며 브라우저 오류 기록은 없었습니다. 검증 프로필과 임시 도구는 배포본에 포함하지 않습니다.
- 실제 실행 주소 127.0.0.1:5173의 두 탭을 v0.4로 갱신했습니다. 로그인 캐릭터 0개와 서로 다른 밝기로 변하는 등불을 확인했으며, 이 주소의 실제 플레이 진행은 검증에 사용하지 않았습니다.
- 온라인 계정/서버, 실시간·비동기 PVP, 길드, 실제 결제/광고, 시즌 운영은 연결하지 않았습니다.
- 지역별 기본 배경은 6장입니다. 맵 이름은 기획 풀을 따르지만 모든 맵과 20보스마다 별도 배경을 만든 상태는 아닙니다.
