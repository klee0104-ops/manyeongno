# 만령로 v0.10.0 테스트 안내

플레이: https://klee0104-ops.github.io/manyeongno/

버그·의견: https://github.com/klee0104-ops/manyeongno/issues/new/choose

지인에게 위 게임 링크만 전달하면 됩니다. 게임을 하는 데 GitHub 가입은 필요하지 않습니다. 별도 소개 글을 게시하지 않는 링크 공유용 테스트이며, 링크를 받은 누구나 접속할 수 있습니다.

## 시작

1. PC 또는 모바일 브라우저로 플레이 링크를 엽니다.
2. 닉네임을 입력하고 여정을 시작합니다. 가입이나 결제는 없습니다.
3. 로딩 후 **스토리 감상하기** 또는 **바로 탐험하기**를 선택합니다.
4. 이야기는 탐험 화면의 **이야기 감상**에서 다시 볼 수 있습니다.

처음 접속하면 그림과 음성을 내려받습니다. 모바일에서는 Wi-Fi 환경을 권장합니다. 음성이 들리지 않으면 음성 재생 버튼과 기기 음량을 확인하세요.

## 10분 테스트 순서

| 순서 | 해볼 것 | 확인할 점 |
|---|---|---|
| 1 | 프롤로그와 초행 길잡이 | 한국어 음성, 성장 → 첫 승리 → 임무 보상의 실제 진행 |
| 2 | 첫 스테이지 탐험 | 공격자가 계속 보이는지, 실제 접근·접촉·복귀, 원거리 시전, 피격 반동, 기술명 음성·끄기, 일시정지·재개 |
| 3 | 도감 → 요괴도감 | 목차 선택, 앞뒤 책장, 전신 확대, 읽기 쉬운 글자 |
| 4 | 각성비록 | 기본 도감과 분리, 단계별 모습과 효과, 전투 모형 |
| 5 | 소환 | 상점 입장 로딩, 할머니 인사, 요괴 소환 / 일반 상점 선택 |
| 6 | 일반 상점 | 구매 전 가격·수량 확인, 취소, 구매 후 재화·보유량 |
| 7 | 새로고침 | 닉네임·요괴·재화·진행 상태가 이어지는지 |
| 8 | 프로필 수정 | 닉네임·보유 요괴 초상·칭호 변경 및 저장 |
| 9 | 구미호 상세에서 연속 레벨업 | 흰 사각 배경이 없는 전신 그림, 스크롤과 버튼 위치 유지 |
| 10 | 평온 5·10·15단계 완료 | 구간 이야기 음성 재생 후 다음 탐험으로 연결, 감상 목록 해금 |

마음에 든 점과 불편했던 점도 좋습니다. 특히 책 넘김 속도, 전투 타격감, 대기 동작, 모바일 버튼 크기와 글자 크기를 알려주세요.

## 새 콘텐츠 확인

- 탐험 화면에서 연속 탐험을 켜고 승리 후 다음 단계로 자동 이동하는지, 중지 버튼이 작동하는지 확인합니다. 처음 보는 구간 이야기는 건너뛰지 않고 멈춥니다.
- 시련 → 일일 던전에서 승리 보상과 남은 횟수를 확인합니다. 입장 즉시 횟수와 행동력을 소비하므로 패배·후퇴·새로고침 시에도 반환되지 않습니다.
- 미궁에서 다음 층으로 이동하고, 나갔다 돌아와도 최고 기록이 남는지 확인합니다.
- 책의 이전/다음 기록과 각성비록에서 그림·글자가 거울처럼 뒤집히지 않는지 확인합니다.
- 궁극기 타격 효과와 2배속·4배속, 일시정지·재개를 확인합니다.

## 저장과 구현 범위

진행 상황은 기기·브라우저·접속 주소별로 저장됩니다. 다른 기기로 옮기려면 게임 설정의 저장 파일 내보내기/불러오기를 사용하세요. 비공개·시크릿 브라우저나 브라우저 데이터 삭제 시 저장이 사라질 수 있습니다.

현재는 로컬 프로필을 사용하는 테스트 빌드입니다. 온라인 계정·PVP·길드·실제 결제는 연결하지 않았습니다. 대기 동작은 기존 도트 그림의 영역별 애니메이션이며, 일부 요괴의 각성 모습은 오라 변화로 표현합니다.

## v0.9 전투 확인

1. 1배속에서 만검혼·적염귀왕·지부신구의 기본 공격을 확인합니다. 발을 번갈아 움직이며 접근하고, 무기 접촉 후 돌아와야 합니다.
2. 구미호의 여우불은 손에서 적에게 날아가며 잔상은 뒤쪽에 있어야 합니다. 투사체 도착 전에 체력이 줄어들지 않아야 합니다.
3. 적염귀왕 연권은 세 번, 만검혼 연참은 두 번의 타격·숫자·소리가 구분됩니다.
4. 이동/발사 중 일시정지 후 계속하거나 설정을 열고 닫아도 같은 위치에서 이어져야 합니다. 후퇴 후 효과가 남지 않아야 합니다.
5. 이동·타격·복귀 동안 그림이 검게 변하거나 사라지는지, 모바일에서 투사체가 잘 보이는지 확인해 주세요.
